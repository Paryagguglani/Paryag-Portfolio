# Paryag Guglani — Personal Portfolio

Personal Next.js portfolio showcasing my journey in AI/ML and full-stack development. Features interactive 3D visuals, project showcases, skills, experience, and contact information.

## Features

- 3D AI Developer Workspace built with React Three Fiber and Drei
- Clickable holographic nodes that open live project details
- Recruiter-friendly sections: Hero, Projects, Skills, Experience, Contact
- Unique interactive elements: mini AI chatbot, skill heatmap, live node preview
- Dark neon theme with glassmorphism UI and mobile-first design

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the portfolio.

## Build

```bash
npm run build
npm run start
```

## Deployment

Deploy on Vercel with the default Next.js settings. This app is ready for production.
